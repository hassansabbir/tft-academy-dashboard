# TFP Academy Dashboard

A modern web-based dashboard for TFP Academy built with React, TypeScript, and Vite.

## 🚀 Features

- **Frontend Framework**: React 18 with TypeScript for robust, type-safe code.
- **Build Tool**: Vite for incredibly fast development server and optimized production builds.
- **State Management**: Redux Toolkit & React-Redux.
- **Routing**: React Router v6.
- **UI Components & Styling**: Tailwind CSS combined with Ant Design for beautiful, responsive interfaces.
- **Form Handling**: React Hook Form for performant, flexible, and extensible forms.
- **Localization**: i18next & react-i18next for multi-language support.
- **HTTP Client**: Axios for API requests.

## 📋 Prerequisites

- **Node.js** (v16, v18, or v20+ recommended)
- **npm**, **yarn**, or **pnpm**

## 🛠️ Getting Started

1. **Install dependencies**
   ```bash
   npm install
   ```

2. **Start the development server**
   ```bash
   npm run dev
   ```
   The application will be available at `http://localhost:5173`.

## 📜 Available Scripts

In the project directory, you can run:

- `npm run dev`: Starts the Vite development server.
- `npm run build`: Type-checks and builds the app for production to the `dist` folder.
- `npm run preview`: Previews the production build locally.
- `npm run lint`: Runs ESLint to check for code quality issues.
- `npm run type-check`: Runs TypeScript type checking without emitting files.
